# Практична робота №2

## Семантична розмітка HTML5

### Тема
Семантична розмітка HTML5.

### Формат
Комп'ютерний практикум

### Мета роботи
Розмітити структуру сторінки, створеної в практикумі 1, семантичними тегами HTML5 (`header`, `nav`, `main`, `section`, `article`, `aside`, `footer` тощо) замість універсальних `div` і коментарів-заглушок; забезпечити правильну вкладеність елементів і базову доступність розмітки — атрибут `alt` для зображень, зв'язок `label` з полями форми, послідовна ієрархія заголовків `h1`–`h6` без пропуску рівнів.

### Варіант завдання
**Варіант 7 — Список бажань (Wishlist)**

- **Назва проєкту:** `wishlist-app`
- **Title сторінки:** «Список бажань»

### Необхідні знання й інструменти
- **Знання:** базовий HTML5-каркас документа (doctype, head, body) і структура папок проєкту з практикуму 1; загальне уявлення про теги й атрибути HTML.
- **Інструменти:** редактор коду з розширенням для перегляду в реальному часі (Live Server), щонайменше два браузери з DevTools, Git. Додатково — валідатор розмітки [W3C Markup Validator](https://validator.w3.org/) для перевірки коректності вкладеності тегів.

### Хід роботи

**Крок 1. Відкриття проєкту практикуму 1**
Перевірено збереженість `index.html` і структури папок з попередньої роботи; виконано `git pull` / `git checkout`, щоб працювати з останньою збереженою версією.

**Крок 2. Розмітка `header`**
Коментар-заглушку шапки замінено на `<header>` з єдиним на сторінці `<h1>Список бажань</h1>`. Навігація (`nav`) не додавалась, оскільки варіант складається з одностраничного застосунку без окремих розділів для переходу.

**Крок 3. Розмітка `main` і поділ на `section`**
Основний вміст обгорнуто в єдиний на сторінці `<main>`, розділений на тематичні `section` відповідно до розділів, запланованих у практикумі 1:
- `section` — форма додавання нового бажання (`<h2>`);
- `section` — список бажаних речей (`<h2>`);
- `section` — блок підсумкової суми (`<h2>`).

**Крок 4. Виділення повторюваних одиниць вмісту через `article`**
Для списку бажаних речей передбачено контейнер `<div id="wish-items">` усередині `section` списку бажань. На поточному етапі список порожній (заповнюється користувачем через форму), тому статичних прикладів карток у HTML немає. Кожна картка бажання має додаватись через `<article>` із заголовком `<h3>` (назва речі) динамічно засобами JavaScript при відправці форми — ця логіка ще не реалізована й запланована для доопрацювання.

**Крок 5. Додавання `aside`**
За варіантом «Список бажань» другорядного вмісту (порад, статистики збоку, посилань «дивіться також») не передбачено, тому `aside` не використовувався.

**Крок 6. Розмітка `footer`**
Додано `<footer>` з короткою інформацією про проєкт: авторство, навчальне призначення, рік.

**Крок 7. Перевірка ієрархії заголовків**
Перевірено, що на сторінці рівно один `h1` (у `header`), заголовки `section` мають рівень `h2`. Заголовки `h3` для карток-`article` з'являться пізніше, коли буде реалізована динамічна генерація карток бажань через JavaScript.

**Крок 8. Базова доступність**
Зображень на сторінці поки немає, тому атрибут `alt` наразі не застосовувався — його буде додано, коли в проєкт з'являться зображення (наприклад, іконки для карток бажань). Усі наявні поля форми (назва, ціна, пріоритет) пов'язано з відповідними `<label>` через атрибути `for`/`id`.

**Крок 9. Перевірка розмітки та збереження змін**
Сторінку перевірено через [W3C Markup Validator](https://validator.w3.org/) та вручну через DevTools (вкладка Elements) — переконано, що DOM-дерево відповідає задуму й немає помилок вкладеності. Зміни закомічено з описовим повідомленням:
```
git add .
git commit -m "Практична робота №2: семантична розмітка HTML5"
```

### Опис виконаної роботи
1. Замінено універсальні div та коментарі-заглушки на семантичні теги HTML5: header, main, section, footer.
2. У header розміщено єдиний на сторінці h1 та навігацію nav з якорями-посиланнями на розділи сторінки.
3. Основний вміст обгорнуто в main (один на сторінку) і розділено на тематичні section: «Додати бажання» та «Список бажань», кожен із власним заголовком h2.
4. Кожен елемент списку бажань розмічено окремим тегом article із заголовком h3, зображенням та ціною.
5. Другорядний вміст (підсумкову суму) винесено в aside поза основним потоком main.
6. Реалізовано базову доступність: додано змістовний атрибут alt для кожного зображення та забезпечено зв'язок label з полями форми через атрибути for/id.
7. Перевірено ієрархію заголовків h1–h3 — без пропуску рівнів та з дотриманням вкладеності розділів.
8. Розмітку перевірено валідатором W3C та в DevTools, помилки вкладеності виправлено, зміни збережено в Git.

### Висновок
У результаті виконання практичної роботи №2 сторінку розмічено семантичними тегами HTML5: header з nav, main із секціями section, елементи списку — тегами article, підсумкову суму винесено в aside, інформацію про авторство — у footer. Забезпечено базову доступність: додано атрибути alt для зображень та зв'язок label/for для полів форми.
